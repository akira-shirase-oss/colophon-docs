---
title: "The Studio's theme follows your system until you flip it, with one button"
date: 2026-11-18
type: Improvement
areas: [Studio]
---

The Light / Dark / System menu in the header is now one button. Until you press it, the Studio follows your operating system's light or dark setting, and changes with it. Pressing it switches to the other theme, and your choice survives a reload. If you press it again so that the theme matches your system once more, the Studio goes back to following the system. That's why "System" doesn't need its own menu item any more.

Screen readers announce the button as a toggle, "Dark theme", either pressed or not, so it doesn't read out a label that changes under you. The command palette (<kbd>⌘K</kbd> or <kbd>Ctrl K</kbd>) has the same action, **Switch light / dark**. If your system asks for more contrast, the Studio uses its higher-contrast colours in both themes. If you've asked for reduced motion, the theme changes without the circle animation.
