The side panel of the entry editor is now three blocks, so its most important part is clear at a glance:

- **A status card.** It shows the entry's status badge and its save state on one row, then one sentence such as *Live in Release 3 · edited since*. Below that is a single primary button for the next step: **Publish**, **Publish changes**, **Publish again**, **Ask for review**, or **Review the request** while the entry waits in one. When readers already have this version, there is no button at all. Everything else is under **⋯ More**: Copy public link (offered only when the live version is public), Duplicate and Technical details, with **Unpublish…** kept apart at the bottom.
- **Language.** One row shows the entry's language and its other-language versions. The **Translate** dialog asks for the source language first if none is set, and offers only languages that aren't taken yet. It is disabled, with the reason given, when unique fields would clash.
- **Details**, closed until you open it.

The status now follows the content, not just the last action. A draft whose content is the same as the live version shows **Live**, with nothing to publish. **Taken down** and **In review** come from what readers and the publish requests actually show.

Elsewhere in the editor:

- The entry's title is the page heading, and you can edit it in place.
- **History** groups saves into sittings, one person's saves within five minutes, showing who, when and what changed.
- Comments open in a drawer that doesn't block the page.
