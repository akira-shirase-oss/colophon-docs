**Linked from** lists the entries whose fields link to the one you're editing. Before you change or take down an entry, it tells you what would be affected. It used to sit outside the editor's tabs, above Comments and History, as if it belonged to every tab. Now it's at the end of the **Content** tab, next to the fields it relates to.

Each row names the entry, its collection and the field that holds the link, with a status badge:

- **Readers see this link**: the link is in a published release, so readers of your site follow it today.
- **In a draft**: only an unpublished draft links here. Nothing live depends on it yet.

If you're not allowed to read an entry that links here, its row says *An entry you can't see*. You still learn that the link exists, but not what's in that entry.

The same information is available from the API as the entry's inverse references. The linked-entries guide shows both.
