---
title: "Search lives in the header only, with a search icon on phones"
date: 2026-11-18
type: Improvement
areas: [Studio]
---

The sidebar had a **Search** item that did the same thing as the search button in the header, so it has been removed. There's one place to search now: the header, or <kbd>⌘K</kbd> / <kbd>Ctrl K</kbd> on a keyboard.

A phone has neither the wide header button nor a keyboard shortcut, so there the header shows a search icon that opens the same search. It jumps to any page of the project, or finds entries by title in every collection; the titles are searched on the server, so entries you haven't opened yet are found too.
